## 📦 NPM Package — `@yashu_jaat01/ai-persona`

> A fluent AI SDK and CLI for terminal chat, AI personalities, project integration, and simple local RAG.

```bash
npm install @yashu_jaat01/ai-persona
```

**Features:**
- 🧙 Interactive setup wizard (`npx ai-persona init`)
- 💬 Terminal chat mode (`npx ai-persona chat`)
- 🔌 SDK-based AI usage in any JS/TS project
- 📄 Local RAG for `.txt` and `.md` files
- 🌐 Multi-provider: Google Gemini, OpenAI, Anthropic
- 🔒 Use-case feature locking (`cli` / `sdk` / `rag` / `both`)

**Quick SDK Usage:**
```javascript
import { ai } from '@yashu_jaat01/ai-persona';

const reply = await ai
  .personality('Senior developer')
  .chat('Explain closures in simple words');

console.log(reply);
```
